# 清洗车防撞报警系统

基于 STM32F103 的多传感器防撞报警系统：4 路超声波 + 1 路倾角传感器实时采集，三级声光报警，CAN 总线上报，串口屏实时显示。

## 一、硬件选型

### 主控

| 器件 | 型号          | 说明                                   |
| ---- | ------------- | -------------------------------------- |
| MCU  | STM32F103C8T6 | 72MHz Cortex-M3，64KB Flash / 20KB RAM |

### 传感器

| 器件                                    | 数量 | 接口                             | 协议参数                             |
| --------------------------------------- | ---- | -------------------------------- | ------------------------------------ |
| 超声波测距模块（量程 50~500mm）         | 4 路 | USART2 → RS485 总线（共享）      | Modbus RTU，9600-8N1，从机地址 01~04 |
| 倾角传感器 SMSA11-v15（单轴 Roll ±15°） | 1 路 | USART3 → RS232（MAX3232 转 TTL） | Modbus RTU，115200-8N1，从机地址 05  |

> 超声波 4 路共享一条 RS485 总线，通过不同从机地址区分；倾角为 RS232 电平，经 MAX3232 模块转 TTL 后接入。

### 输出与人机接口

| 器件                              | 引脚              | 功能                                               |
| --------------------------------- | ----------------- | -------------------------------------------------- |
| 有源蜂鸣器（高电平触发）          | PB0               | 分级鸣响：一级 1Hz 间歇 / 二级 5Hz 间歇 / 三级常响 |
| 板载绿色 LED                      | PC13              | 整体报警状态指示（慢闪/快闪/常亮）                 |
| 外接红色 LED                      | PB1               | 与蜂鸣器节奏同步，反映整体最高报警等级             |
| CAN 收发器（SN65HVD230 / VP230）  | PB8/PB9           | 250kbps，标准帧 ID 0x100，只发不收                 |
| DGUS 串口屏（DC48270DN043，4 寸） | USART1 (PA9/PA10) | 实时显示 4 路距离、倾角、报警等级                  |
| USB-TTL（调试用）                 | USART1            | 115200，与串口屏二选一使用                         |

### 供电

- STM32 及外设模块：3.3V / 5V
- 倾角传感器：9~33V 宽压，需外部 12V/24V 供电（不可直接接板载电源）

## 二、软件架构

### 总体设计：前后台架构

```
┌────────────────────────────────────────────────┐
│  前台（中断）                                    │
│  TIM2 每 100ms 置位 g_sensor_ready 标志          │
└──────────────────┬─────────────────────────────┘
                   ↓
┌────────────────────────────────────────────────┐
│  后台（主循环）                                   │
│  ├─ 检测标志 → Sensor_Task()                    │
│  │    ├─ US1~US4 逐路 Modbus 查询（各约 22ms）    │
│  │    ├─ 倾角查询                                │
│  │    ├─ 报警等级计算 + 状态机消抖                 │
│  │    ├─ CAN 状态帧发送                          │
│  │    └─ 串口屏/调试打印                          │
│  └─ 每 50ms 刷新 LED + 蜂鸣器（独立节奏）          │
└────────────────────────────────────────────────┘
```

中断里只置标志、不做重活——Modbus 查询单轮约 90ms 且含阻塞等待，放进中断会饿死低优先级中断（含 SysTick）。

### 模块划分

├── alarm.c/h            报警等级计算 + 升降级消抖状态机

### 报警阈值（三级）

| 等级 | 超声波（取 4 路最小值） | 倾角 \|Roll\| | 声光表现         |
| ---- | ----------------------- | ------------- | ---------------- |
| 正常 | ≥120mm                  | <2°           | 灯灭、静音       |
| 一级 | 100~120mm               | 2~3°          | 慢闪、1Hz 间歇鸣 |
| 二级 | 80~100mm                | 3~4°          | 快闪、5Hz 间歇鸣 |
| 三级 | <80mm 或传感器故障      | ≥4°           | 常亮、长鸣       |

整体等级 = max(距离等级, 倾角等级)。升级立即生效，降级经消抖确认。

### 关键机制：超声波盲区锁定

超声波传感器在 <80mm 近距离时读数乱跳（物理盲区），直接使用会导致报警闪断。处理策略：

1. 读到 <80mm → 进入盲区锁定，距离强制 0，按三级报警；
2. 盲区期间读到 ≥80mm → 连续 3 帧确认才解除（过滤近距离偶发假数据，防闪断）；
3. 盲区期间坏帧/超时 → 保持锁定状态不变；
4. 上电稳定期：前 20 帧忽略近距离读数，防止传感器初始化期误报；
5. 传感器在线标志：从未收到过有效数据的传感器超时不触发故障报警（未接线/未通电场景）。

### 串口接收实现说明

Modbus 应答帧长度不固定，未使用 HAL 定长阻塞接收，而是**轮询 RXNE 标志 + 直接读 DR 寄存器 + 空闲超时判帧**：

- 超声波路（9600bps）：空闲超时 4ms ≈ 3.5 字符时间，符合 Modbus RTU 帧静默判帧标准；单路总超时 25ms（帧传输约 16ms + 裕量）
- 接收缓冲区 32 字节上限保护，超长数据丢弃，防止越界写坏内存

### CAN 协议（标准帧 ID 0x100，250kbps，8 字节）

| 字节          | 内容                                             |
| ------------- | ------------------------------------------------ |
| Byte0         | [bit7:4] US1~US4 故障标志，[bit3:0] 整体报警等级 |
| Byte1 / Byte2 | 超声波 / 倾角独立报警等级                        |
| Byte3~6       | US1~US4 距离（cm，0xFF=无效，>254 饱和）         |
| Byte7         | 倾角 Roll + 128（-128~127° 映射到 0~255）        |

## 四、可以改动的方向

所有可调参数集中在各头文件，标注【可微调】：

| 参数                        | 位置                  | 当前值       | 调整场景                   |
| --------------------------- | --------------------- | ------------ | -------------------------- |
| 盲区边界 US_BLIND_MM        | us_sensor.h           | 80mm         | 近距离仍乱跳→提高          |
| 盲区保持帧数 BLIND_HOLD_CNT | us_sensor.h           | 60           | 盲区锁定期长/短            |
| 盲区解除确认帧数            | us_sensor.h           | 3            | 假数据多→加大；响应慢→减小 |
| 距离报警阈值                | alarm.h               | 120/100/80mm | 按车型安全距离重标定       |
| 倾角报警阈值                | alarm.h               | 2/3/4°       | 按路面工况调整             |
| 降级消抖 DEBOUNCE_DOWN      | alarm.h               | 1            | 报警频繁跳变→2 或 3        |
| 采集周期                    | CubeMX TIM2 (PSC/ARR) | 100ms        | 提速需配合非阻塞改造       |
| 蜂鸣器触发方式              | indicator.h           | 高电平       | 换低电平触发蜂鸣器改宏     |

### 功能扩展方向

- **非阻塞采集**：当前为阻塞式轮询（单轮约 90ms），可改造为 UART 中断/DMA + 状态机，采集周期可压缩且 CPU 可休眠；
- **CAN 接收**：预留扩展为双向通信（接收上位机配置命令，如远程修改阈值）；
- **更多传感器**：RS485 总线可直接挂更多超声波（改地址、扩数组即可）；倾角可升级双轴；
- **数据滤波**：目前盲区机制为主，可叠加滑动平均/中值滤波进一步平滑距离值；
- **低功耗**：当前主循环 `HAL_Delay(5)` 轮询，可改 WFI 休眠 + 事件唤醒。

## 五、已知限制

- 采集为阻塞式，单轮最坏（全超时）约 125ms，会偶尔超 100ms 周期，下一循环补上；
- RS485 方向依赖模块自动收发（未手动控制 DE/RE），更换不带自动换向的模块需增加方向控制；
- 串口屏与 USB-TTL 调试共用 USART1，同时使用会冲突。
